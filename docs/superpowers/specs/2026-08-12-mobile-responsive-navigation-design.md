# 睿见投研手机端响应式导航设计

日期：2026-08-12  
状态：已确认

## 1. 背景与问题

睿见投研已部署到京东云，桌面端使用 232px 固定侧栏。现有 CSS 在屏宽小于 900px 时把侧栏压缩为 64px，并隐藏菜单文字，只保留每个菜单项前的 6px 圆点。这导致手机端出现一列无法辨认的圆点，同时正文被永久占用 64px，顶栏标题、会员信息和内容卡片被进一步挤压。

本次目标是完成全站手机端响应式优化，而不是只修复首页截图中的侧栏表现。

## 2. 已确认方案

采用“顶部菜单按钮 + 左侧抽屉导航”。桌面端现有侧栏和视觉风格保持不变。

### 2.1 响应式断点

- 屏宽大于或等于 901px：保留当前 232px 桌面侧栏。
- 屏宽 601px 至 900px：隐藏固定侧栏，使用抽屉导航；内容可根据空间保留部分双列布局。
- 屏宽小于或等于 600px：使用抽屉导航；主要内容单列，短数据卡片可保留双列。

断点以 CSS 媒体查询为准，初始渲染不依赖 JavaScript 判断屏宽，避免页面闪烁和服务端状态差异。

### 2.2 手机顶栏

- 左侧增加至少 44px 点击区域的菜单按钮，并提供中文无障碍标签“打开导航菜单”。
- 顶栏显示当前页面标题。
- 会员等级、用户名和退出入口不再挤占手机顶栏，统一移动到抽屉底部。
- 顶栏保持吸顶，并适配移动设备顶部安全区域。

### 2.3 导航抽屉

- 从左侧滑出，宽度约为屏幕的 82%，并设置合理最大宽度。
- 显示品牌名称、全部主导航、账户导航以及管理员可见的系统配置入口。
- 当前页面继续使用橙色竖线和浅色背景标识。
- 抽屉底部显示会员等级、用户名和退出按钮。
- 支持通过菜单项、关闭按钮、遮罩、Escape 键关闭。
- 路由变化后自动关闭抽屉。
- 打开时锁定背景滚动；关闭或组件卸载时恢复滚动状态。
- 抽屉和遮罩位于页面内容及吸顶顶栏之上，不影响桌面端层级。

### 2.4 页面内容适配

- 手机正文使用完整可视宽度，缩小内容区与卡片内边距。
- 首页指数卡片在窄屏使用紧凑双列；极窄宽度仍可自然降为单列。
- 双栏、三栏和四栏业务布局在手机端统一降为单栏。
- 筛选按钮允许换行；必须连续展示的标签组可以在组件容器内横向滚动。
- 宽表格由就近容器承担横向滚动，禁止整个页面横向溢出。
- 图表、热力图、长文本和代码块不得突破正文宽度。
- 弹窗使用安全边距限制宽度，操作按钮保持至少 44px 点击高度。
- 登录页维持现有独立布局，不引入应用抽屉。
- 保持现有配色、边框优先的卡片风格和桌面信息结构，不进行无关视觉重构。

## 3. 组件边界与状态

主要修改集中在应用外壳与共享样式：

- `Layout.tsx` 负责抽屉开关状态、关闭事件、路由切换联动和移动端用户操作区。
- `app.css` 负责桌面/手机显示切换、抽屉动画、遮罩、安全区域、共享卡片及内容响应式规则。
- 页面组件只在共享规则无法可靠覆盖时做最小的语义类名调整，不复制各自的抽屉逻辑。

抽屉状态仅保存在当前页面运行内，不写入本地存储。刷新或重新进入应用时默认关闭。

## 4. 失败与边界处理

- JavaScript 尚未执行时，CSS 必须保证手机端不会显示圆点侧栏或形成整体横向滚动。
- 快速切换路由时，抽屉应可靠关闭，不遗留页面滚动锁。
- 用户从手机旋转到桌面宽度时，桌面侧栏正常出现，抽屉遮罩和滚动锁清理。
- 管理员入口继续由现有角色判断控制，普通用户不可见。
- 退出行为复用现有认证逻辑，不改变登录和权限模型。

## 5. 测试策略

开发阶段遵循 TDD：先增加会失败的布局行为测试，再实现抽屉和响应式样式。

测试覆盖：

- 布局组件：菜单按钮、抽屉可见性、关闭按钮、遮罩、Escape、路由变化和退出入口。
- 权限：管理员可见系统配置，普通用户不可见。
- 构建：TypeScript 与 Vite 生产构建通过。
- 浏览器 QA：390px、430px、768px、1440px 四种视口检查首页及主要页面。
- 回归：桌面侧栏、登录页、弹窗、表格、筛选器和导航跳转正常。

## 6. 验收标准

1. 390px 手机宽度不再出现圆点侧栏。
2. 页面不存在整体横向滚动条。
3. 全部导航入口文字清晰、可点击并正确跳转。
4. 抽屉可通过菜单项、关闭按钮、遮罩和 Escape 正常关闭。
5. 打开抽屉时背景不滚动，关闭后恢复。
6. 首页首屏可看到页面标题和至少两张指数卡片。
7. 表格、筛选器、弹窗、会员信息和退出操作在手机端可用。
8. 390px、430px、768px、1440px 实测通过。
9. 前端构建及相关自动化测试全绿。
10. gstack `/review` 与 `/qa` 均通过后，才允许提交实现或推送部署。

## 7. 非目标

- 不修改后端接口、数据库或认证模型。
- 不重新设计桌面端视觉体系。
- 不新增底部导航或自定义图标库。
- 不改变业务模块、会员规则或菜单权限。
- 不在本任务中部署到京东云；是否推送和部署由用户在实现验证完成后另行授权。
