## 1. 注册与登录

### 注册账户

1. 打开系统页面，点击右上角"注册"标签。
2. 填写用户名、邮箱、密码。
3. 点击"获取验证码"，系统会向你的邮箱发送 6 位数字验证码。
4. 输入验证码后点击"注册"按钮。

> **名词解释：验证码** — 一组发送到你邮箱的 6 位数字，用来证明这个邮箱确实是你本人的。验证码 5 分钟内有效。

### 登录

在登录页输入"邮箱或用户名"和密码，点击"登录"。登录后系统会记住你的身份，刷新页面不会掉线。

### 忘记密码

1. 点击"忘记密码"标签。
2. 输入注册邮箱和新密码。
3. 获取邮箱验证码后提交即可重置密码。

### 新用户福利

注册成功后，系统自动赠送 **C 档会员 3 天试用**，可以体验大部分付费功能。试用期结束后自动降为免费用户。

## 2. 首页行情

首页展示 A 股市场概览，帮助你快速了解当天市场动态。

### 大盘指数卡片

页面顶部显示上证指数、沪深 300、科创 50、深证成指、创业板指的实时涨跌幅。数据每分钟自动更新，也可以点击"刷新"按钮手动更新。

### 当天热门行业与题材

首页会分别加载“热门板块”（行业分类）和“热门题材”（市场主题）。列表按当天热度分排序，名称和排名会随交易日变化，不再使用固定的六个板块。

> **名词解释：行业板块** — 按主营业务把股票归类，例如银行、电子、医药；**题材** — 围绕同一事件或主题形成的股票集合，例如人工智能、低空经济。

每项会显示涨跌幅、热度分和趋势标签：

- **热度分**：由涨跌强度、成交活跃度和上涨宽度综合计算，只用于同一交易日的横向比较。
- **升温 / 降温 / 持平**：将当天排名与历史盘后快照比较，帮助识别热点是否延续。
- **交易日标记**：实时数据和历史快照都会显示数据日期。实时来源不可用时会标记“历史数据”和最近有效日期。

点击行业或题材后，页面会加载该板块的代表个股，包括名称、代码、价格、涨跌幅和成交额。行业与题材分开请求，某一模块暂不可用不会影响其他模块。

### 大盘云图

云图展示最多 80 个行业或题材，面积优先按板块市值计算，颜色表示涨跌方向（红涨绿跌）。点击云图节点可查看该板块的代表股，点击“返回云图”回到全市场；顶部的“行业 / 题材”按钮可以切换口径。

### 盘后快照

系统在交易日 15:10、15:20、15:30（Asia/Shanghai）尝试保存热点和代表个股快照。快照用于次日趋势比较，不会伪造实时行情；若当天没有可用数据，页面会保留明确的空态或错误提示。

## 3. 股票分析

这是系统的**核心功能**。输入一个 A 股代码，AI 会从多个角度帮你分析这只股票值不值得买。

### 单股分析

1. 切换到"单股分析"标签。
2. 输入 6 位股票代码（如 `600519` 代表贵州茅台）。
3. 点击"开始分析"。

分析过程中，5 位 AI 分析师会分别从以下角度出具报告：
- **技术面分析师**：看 K 线形态、均线、MACD、RSI 等技术指标
- **基本面分析师**：看市盈率、市净率、ROE 等财务数据
- **资金面分析师**：看主力资金是流入还是流出
- **新闻分析师**：看最近新闻是利好还是利空
- **情绪分析师**：看市场对这只股票的情绪倾向

最后，首席分析师综合所有报告，给出最终决策卡：评级（买入/持有/卖出）、目标价、止损价、置信度、入场区间等。

### 批量分析

切换到"批量分析"标签，一次输入多只股票代码（逗号或换行分隔），最多 50 只。系统会依次分析并汇总结果。

### 历史记录

切换到"历史记录"标签，可以看到你之前做过的所有分析。点击"查看"可以回看完整报告。

### 导出 PDF

在报告详情页，点击右下角"导出 PDF"按钮，可以下载完整的分析报告 PDF 文件，方便存档或分享。

> **注意：** 每份报告底部都有免责声明——"本分析仅供参考，不构成任何投资建议。"

## 4. 主力选股

这个模块帮你从全市场中筛选出主力资金正在关注的股票。

### 怎么用

1. 点击"开始选股"按钮。
2. 系统自动执行选股流水线：先按主力资金净流入取约 40 只候选股，再用策略规则筛选，然后 5 位 AI 分析师逐一分析，最终精选出 3-5 只推荐。
3. 过程中可以看到各阶段数量漏斗和 Token 消耗。
4. 每只推荐股附有入选理由和排除理由。

### 历史记录

"历史记录"标签可以回看历次选股结果。

> **名词解释：主力资金** — 大机构（基金、券商、外资）买卖股票的资金。主力资金持续流入通常意味着机构看好这只股票。

## 5. 智策板块

这个模块每天自动生成板块分析报告，帮你判断哪些行业板块值得关注。

### 4 位 AI 分析师

- **宏观策略师**：从宏观政策、经济数据角度分析
- **板块诊断师**：按申万二级行业分类做诊断
- **资金流向分析师**：看各板块资金进出情况
- **市场情绪解码员**：分析市场情绪对板块的影响

### 板块多空预测

每天自动产出看多/看空列表，每条附置信度（满分 10 分）、逻辑和风险提示。

### 操作节奏建议

报告中包含操作节奏建议、风险触发条件和核心跟踪指标。

## 6. 智瞰龙虎榜

龙虎榜是交易所每天公布的异动股名单，反映游资和机构的动向。

### 怎么用

1. 选择时间范围（3/5/10/15/20/30 天）。
2. 点击分析按钮。
3. 系统会输出：上榜记录数、上榜股票数、总净流入、活跃游资数、信心评分。
4. 推荐股票 Top10 表：按评分排名，附净流入买卖拆分、游资成功率等。

> **名词解释：龙虎榜** — 交易所每天公布的涨跌幅或换手率异常的股票名单。能看到哪些游资（短线高手）和机构在买卖。

## 8. 实时监测

## 13. 管理员：大模型中心

只有管理员能看到“系统配置 → 大模型中心”。普通用户不需要配置模型，也不会看到密钥。

### 添加、测试、启用、设默认

1. 点击“添加模型”，选择 DeepSeek、Kimi 或通义千问，填写供应商提供的模型 ID 和 Base URL。
   模型 ID 可以自由填写，不必从固定下拉框选择。
2. 输入 API Key 后点击“测试”。测试请求会真实访问供应商；测试完成后输入框会自动清空，
   页面只保留 `sk-****` 形式的脱敏值。若要保存，重新输入 Key 再点击“保存”。
3. 测试成功后点击“启用”，再点击“设为默认”。新任务只会使用已启用、已验证且未删除的默认模型。
4. 删除前需要输入模型名称确认。当前默认模型不能删除；请先把默认切换到另一条配置。

支持同时配置三家供应商。切换默认只影响之后提交的新任务，正在运行的任务继续使用提交时锁定
的模型配置。页面提示“配置已被其他管理员修改，请刷新后重试”时，先刷新列表再重复操作，
不要凭旧页面强行覆盖。

### 每日 Token 额度与锁停

大模型中心显示当天（北京时间）的 reserved（已预留）和 settled（已结算）Token。额度锁停
表示系统为保护预算暂停新的模型调用；它不会通过刷新页面乐观消失。管理员确认账单和未完成任务
后，填写解锁原因并确认，系统会重新读取服务端额度并记录审计。未知价格会显示“价格未知”，
不会被当成 0 元。

### 错误含义与安全提醒

- “模型未验证”：先点“测试”，确认供应商返回成功，再启用。
- “配置已被其他管理员修改”：另一位管理员刚保存过，请刷新后重试。
- “今日额度已锁停”：等待结算、调整预算或按审计流程解锁，不能通过重复点击绕过。
- “服务未就绪”：管理员应检查 PostgreSQL、Redis、密钥环和真实供应商连接。

系统不提供模拟运行开关，所有模型测试与任务调用均使用真实服务端结果。API Key 不会写入日志、
报告或浏览器持久存储；密钥轮换由运维在维护窗口完成，旧配置在轮换确认前必须仍可解密。

## 14. 管理员：数据源配置

进入“系统配置 → 数据源配置”即可管理行情、财务、资金流和资讯来源。普通用户不需要填写数据源凭证。

### 先看来源说明

每张卡片会显示来源名称、免费或凭证类型、支持的能力、默认状态和不可用原因。常用免费来源包括腾讯行情、东方财富、新浪和 RSS；Tushare/KPL 默认关闭，只有管理员保存合法凭证并测试通过后才会参与对应能力。字段名称和是否 secret 由后端注册表提供，页面不会把 Token 文案写死。

### 按能力测试与选择

1. 在路由表中选择具体能力，例如“大盘指数、个股实时行情、日 K、财务、资金流、股东户数、龙虎榜”。
2. 点击对应卡片的“测试连接”。免费来源可直接测试；Tushare Pro 输入来自 Tushare Pro 控制台的 Token（只用于 Tushare 的 `kpl_*` 数据集，不是开盘啦原生 Token），开盘啦原生必须同时输入开盘啦合法账号 `UserID` 和 `Token`，不能填 Tushare Token。输入新凭证会临时测试，留空则测试服务端已保存的加密凭证。
3. 自动模式按首选→备用顺序尝试，支持勾选候选来源并上移/下移排序；固定模式只保留一个来源。点击保存后，后续业务请求按服务端配置切换，不需要重启页面。

测试结果会显示在发起操作的那张卡片按钮下方，不会串到其他数据源卡片；页面顶部只显示加载或刷新失败。开盘啦原生卡片的错误“未登录或凭证无效”表示账号、Token 或权限未通过，不代表测试成功。

### 状态和安全

- **fresh**：数据时间在当前能力的有效窗口内。
- **stale**：上游暂时失败，系统返回最近一次有效数据，同时显示原始数据时间和来源。
- **503**：所有已启用来源都不可用，请稍后重试或检查凭证。

Token 只在服务端加密保存，页面、日志、缓存和报告不会显示完整凭证。保存或测试完成后输入框会清空；不要把 Token 写进备注或截图。KPL 原生接口默认禁用，只提供已确认的题材标签、板块排行、板块成分和股票排行四类实验性能力；涨停梯队、强势板块、竞价开盘等未经账号实测的能力不会伪装成可用来源。

分析报告会先采用实时快照估值，财务数据仅补充快照缺失值；行业来自独立公司资料。资金流缺失时显示 `N/A`，不会把缺失伪装成 0。没有配置 `KPL_USER_ID` 与 `KPL_TOKEN` 时，系统会明确记录尚未完成真实开盘啦账号验证，免费行情和基础分析仍可继续。

## 常见问题

**Q：分析报告准确吗？**
A：报告由 AI 根据公开数据生成，仅供参考，不构成投资建议。投资决策请自行判断。

**Q：为什么提示"今日次数已用完"？**
A：你的会员等级每日可用次数有限，升级会员可获得更多次数，或等待次日 0 点重置。

**Q：注册时收不到验证码？**
A：检查邮箱垃圾邮件夹；验证码 5 分钟内有效，过期需重新获取。

**Q：手机上能用吗？**
A：可以，系统已适配手机浏览器（390px 宽度），所有功能均可正常使用。

**Q：定时任务的数据什么时候更新？**
A：板块分析每交易日上午 9:30 自动更新；龙虎榜每交易日 17:05 更新；新闻每 15 分钟采集一次；美股研报每个美股交易日后凌晨更新。
