# OpenCode Go 订阅模型选型报告

> 数据来源：[OpenCode Go 官方文档](https://opencode.ai/docs/zh-cn/go/)（2026-08-07 抓取）
> 用途：为本项目（aistock）的 Codex 编程挑选合适的模型

## 一、OpenCode Go 是什么

- 首月 **$5**，之后 **$10/月** 的订阅制服务，聚合了一批开源编程模型。
- 限额按美元额度计算：**每 5 小时 $12 / 每周 $30 / 每月 $60**。
- 也就是说：模型越便宜，能发的请求越多；模型越贵，额度消耗越快。
- 撞限后可以继续用免费模型，或在控制台开启"使用余额"用 Zen 积分兜底。
- 所有模型都**不用于训练**，除 Grok 4.5 和 GPT 5.6 Luna 留存 30 天外，其余 0 天留存。

## 三、给你的推荐（按用途配 4-5 个就够）

### 主力：GLM-5.2

- $60 满额度的最强档，每月约 4,300 次请求，日常全栈开发够用。
- 单价 $1.40/$4.40 在旗舰级里最便宜，智谱的编程模型口碑一直在线。
- 适合：本项目日常的功能开发、bug 修复、重构。

### 备选主力：Kimi K2.7 Code

- 编程专精模型，每月约 6,750 次请求，比 GLM-5.2 更耐用。
- 适合：和 GLM-5.2 换着用，或 GLM 撞限后顶上。

### 省钱杂活：DeepSeek V4 Flash

- 每月 15 万次请求，等于随便用。
- 适合：改文案、写小脚本、简单问答这类不费脑子的活。

### 攻坚（省着用）：Kimi K3

- 全列表最贵（$3/$15），每月只有约 490 次请求。
- 适合：架构级难题、其他模型反复搞不定的 bug。**别拿它当日常主力，几天就会烧完额度。**

### ~~特殊选项：GPT 5.6 Luna~~（实测不可用）

- 它本应是列表里唯一走 OpenAI Responses API、和 Codex 协议最匹配的模型。
- 但 2026-08-07 实测：国内网络直接返回 `403 This model is not available in your region`，**区域受限不可用**，不要加进模型映射。

### 不推荐的

- **MiniMax M3 / M2.7、Qwen3.x 全系**：走 Anthropic Messages 协议，Codex 不支持直连，cc-switch 里加了也用不了。
- **Grok 4.5**：600 次/月的额度太少，且 30 天数据留存；2026-08-07 实测上游 503 不可用，直接排除。
- **MiMo V2.5 / Pro、Hy3**：轻量档能力一般，杂活有 DeepSeek V4 Flash 就够了。

## 四、cc-switch 填写指南

你 cc-switch 里已经建好 "OpenCode Go" 供应商了，目前缺 API Key。按下面填：

### 基本字段

| 字段 | 填什么 |
|---|---|
| API Key | 登录 [opencode.ai](https://opencode.ai) 的 Zen 控制台 -> 订阅 Go -> 复制 API Key 粘贴进来 |
| Base URL | `https://opencode.ai/zen/go/v1`（你现在已经是这个，不用动） |
| 请求格式 / wire_api | 保持 `responses`（走 cc-switch 本地代理，它会自动转成上游要的格式） |
| 思考深度控制开关 | 保持打开（截图顶部那个绿色开关，把 Codex 的 reasoning.effort 转成上游参数） |

### 模型映射表（菜单显示名 / 实际请求模型 / 上下文窗口）

| 菜单显示名 | 实际请求模型 | 上下文窗口 | 用途 |
|---|---|---|---|
| GLM 5.2 | `glm-5.2` | 204800 | 主力 |
| Kimi K2.7 Code | `kimi-k2.7-code` | 262144 | 备选主力 |
| DeepSeek V4 Flash | `deepseek-v4-flash` | 1000000 | 杂活 |
| Kimi K3 | `kimi-k3` | 204800 | 攻坚，省着用 |

几点说明：

- 你截图里已有 kimi-k3、gpt-5.6-luna、kimi-k2.7-code、deepseek-v4-pro、deepseek-v4-flash、mimo-v2.5-pro：把 gpt-5.6-luna 删掉（区域受限），DeepSeek 两行的上下文窗口补上 `1000000`（和你另一个 DeepSeek 直连供应商保持一致），再按需加 `glm-5.2` 即可。
- 2026-08-07 用你的 key 实测：glm-5.2、kimi-k2.7-code、kimi-k3、deepseek-v4-flash、mimo-v2.5-pro 全部返回 200 可用。
- "实际请求模型"必须和官方模型 ID 一字不差（全小写、带连字符），填错了会报模型不存在。
- **自定义 User-Agent 建议填 Mozilla/5.0 预设**：实测不带浏览器 UA 的请求会被 opencode.ai 的 Cloudflare 直接拦掉（403 错误码 1010）。如果切换后 Codex 报 403，先检查这一项。
- 保存后**重启 Codex** 才会刷新 `/model` 菜单里的模型列表。
- 用的时候在 Codex 里 `/model` 切换：日常挂 GLM 5.2，简单活切 DeepSeek V4 Flash，卡壳了换 Kimi K3。

### 撞限额了怎么办

- 每月 $60 额度花完后，Go 会拦截请求。两个选择：等 5 小时/每周/每月窗口刷新，或在 Zen 控制台开启 "Use balance" 用余额兜底（按官方单价扣，建议只给主力模型开）。
- 用量在 Zen 控制台可以实时看，建议头一周观察一下消耗速度，再决定日常挂哪个模型。
