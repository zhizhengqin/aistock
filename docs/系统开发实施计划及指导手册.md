## 第一部分：先搞懂这些词（名词扫盲）

不用背，遇到不懂回来查即可。按"盖房子"类比记忆。

### 1.1 软件开发基础词

| 名词 | 通俗解释 | 盖房类比 |
|---|---|---|
| 前端（Frontend） | 用户在浏览器里看到和点到的部分 | 房子的装修和家具 |
| 后端（Backend） | 服务器上干活的部分：存数据、算逻辑、调 AI | 房子的水电煤和管家 |
| API（接口） | 前端向后端"点菜"的菜单和窗口 | 传菜口 |
| 数据库（Database） | 存所有数据的大账本（用户、报告、持仓） | 档案室 |
| ORM | 让程序员用代码对象操作数据库，不用手写 SQL | 档案室的智能索引机 |
| SQL | 操作数据库的语言 | 档案管理员的检索口令 |
| 框架（Framework） | 别人写好的"半成品"，在其上填业务（FastAPI、React 都是） | 精装修毛坯房 |
| 库（Library） | 别人写好的工具包，拿来就用（akshare 取股票数据） | 宜家买现成柜子 |
| Git / GitHub | 代码的时光机 + 云端仓库，每改一次存一个版本 | 施工日志 + 异地保险柜 |
| 部署（Deploy） | 把你电脑上的程序搬到服务器上跑起来 | 把样板间变成真房子 |
| 服务器 / 云主机 | 一台 24 小时开着的远程电脑（我们租京东云的） | 买的地皮 |
| 域名 | 网址的名字（如 aistock.xxx.cn），解析到服务器 IP | 门牌号 |
| HTTPS | 给网站传输加密的协议，网址前的小锁 | 防盗门 |
| ICP 备案 | 国内网站必须向工信部登记，否则域名不能解析到国内服务器 | 房产证登记 |

### 1.2 本项目专属词

| 名词 | 通俗解释 |
|---|---|
| LLM（大语言模型） | DeepSeek、Kimi 这类 AI，你给它文字它回文字，是"AI 分析师"的大脑 |
| Prompt（提示词） | 发给 LLM 的"工作指令"，写得好坏直接决定报告质量 |
| Token（LLM 语境） | LLM 的计费单位，1 个汉字约 1-2 个。一次主力选股实测烧 8.3 万个，这就是为什么必须做配额 |
| 多智能体（Multi-Agent） | 让一个 LLM 分饰多角（技术面分析师、基本面分析师……），各写各的报告再汇总，模拟券商研究所 |
| 异步任务 | 慢活（AI 分析要 1-2 分钟）不让页面干等，后台做完再通知前端 |
| 定时任务 | 服务器上按闹钟自动执行的程序（如每天凌晨 3:47 生成美股研报） |
| 配额 | 每个会员等级每天用某功能的次数上限，控制 AI 费用 |
| akshare | 免费的 Python 数据库，一行代码取 A 股行情、财务、龙虎榜数据 |
| 龙虎榜 | 交易所每日公布的异动股票买卖席位名单，是追踪"游资"的官方数据 |
| 申万行业分类 | 券商通用的行业划分标准（如"煤炭开采""消费电子"），板块分析用它 |

### 1.3 工程流程词（团队协作规范里会用到）

| 名词 | 通俗解释 |
|---|---|
| PRD | 产品需求文档：写清楚"做什么、给谁用、怎么算做完" |
| TDD（测试驱动开发） | 先写"考卷"（测试）再写"答案"（代码），保证质量 |
| Code Review | 代码写完后互相检查，找漏洞 |
| CI/CD | 代码一提交，机器自动跑测试、自动发布到服务器 |
| 回归测试 | 改完新功能后，把旧功能再点一遍，确认没碰坏 |
| 里程碑（Milestone） | 大目标切成的小关口，每个关口有可验收的成果 |

### 2.2 每个阶段的统一工作法（gstack + Superpowers 纪律）

每个里程碑都按这个节奏走，不许跳步：

1. **明确需求**：打开《系统详细功能介绍》对应章节 + 参照系统实际页面，确认要做什么；
2. **工程方案**：让 AI 助手出实现方案（改哪些文件、加哪些接口、建哪些表），你确认后开工；
3. **先写测试再写代码**（TDD）：先定义"怎么算对"，再实现；
4. **自测通过**：后端 pytest 全绿；前端页面用 Playwright 实际点一遍（含手机宽度 390px）；
5. **提交**：一个功能一个 git 提交，提交信息写清楚做了什么。

## 第三部分：第 0 阶段 —— 开发环境搭建（手把手）

目标：让你的 Mac 具备全部开发条件。以下命令逐条复制到"终端"（Terminal）执行。

### 步骤 1：安装 Homebrew（Mac 软件管家）

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### 步骤 2：安装基础工具

```bash
brew install git python@3.12 node@22
brew install --cask docker visual-studio-code
```

- `git`：代码版本管理；`python`：后端语言；`node`：前端构建工具；
- Docker Desktop：装完要**打开一次**（在"应用程序"里双击），看到鲸鱼图标常驻菜单栏才算好；
- VS Code：写代码的编辑器。

### 步骤 3：注册账号并拿到"钥匙"

| 账号 | 用途 | 去哪办 |
|---|---|---|
| GitHub | 存代码、自动部署 | github.com 注册 |
| DeepSeek 开放平台 | 拿 LLM API Key（充 10 元够开发期用） | platform.deepseek.com |
| 京东云 | 买服务器 | jdcloud.com 注册 + 实名认证 |
| 域名 | 京东云或阿里云万网购买，如 `xxx.cn`（首年约 30 元） | 随服务器一起买 |

**拿到 DeepSeek Key 后**，形如 `sk-xxxxxxxx`，保存好，这就是 AI 的大脑钥匙。**任何人要都不给。**

### 步骤 4：提交 ICP 备案（同一天做！）

在京东云控制台找到"备案"入口，按指引提交：身份证、域名、网站名称（建议写"个人技术博客"类中性名称更易过审）、承诺书拍照。等短信核验。

### 步骤 5：验证环境

```bash
git --version && python3.12 --version && node --version && docker --version
```

四条都有版本号输出 = 环境 OK。

## 第十部分：M7 —— 部署上京东云（第 8 周）

### 10.1 买服务器

京东云控制台 → 云主机：4C8G、Ubuntu 24.04、系统盘 100G、按量或包月（约 150-250 元/月）。记下公网 IP。安全组放行 80/443/22 端口。

### 10.2 部署步骤（命令级）

```bash
# 1. 本地把代码推到 GitHub
git push origin main

# 2. SSH 登录服务器
ssh root@你的服务器IP

# 3. 服务器上装 Docker
curl -fsSL https://get.docker.com | bash

# 4. 拉代码、配置环境变量
git clone https://github.com/你的名字/仓库名.git /opt/aistock
cd /opt/aistock
cp .env.example .env   # 然后编辑填入 DeepSeek Key、数据库密码等

# 5. 一键启动
docker compose up -d

# 6. 验证
curl http://localhost/api/health
```

备案通过后：域名解析 A 记录指向服务器 IP → 用 acme.sh 申请 Let's Encrypt 免费证书 → Nginx 配置 443 → 浏览器访问 `https://你的域名` 出现小锁。

## 第十一部分：怎么和 AI 编程助手高效协作

你是"产品经理 + 验收员"，AI 助手是"开发团队"。协作口诀：

1. **给上下文，不给碎片**：开工先说"读 docs/ 下四份文档，现在做 Mx 任务 y"，比直接说"帮我写个登录"质量高十倍；
2. **先方案后代码**：让 AI 先输出"要改哪些文件、怎么改"，你确认再动手；
3. **先要测试后要实现**："先写测试，跑红了再实现到绿"；
4. **一次一个功能**：一个会话干一件事，干完提交 git，再开下一件事；
5. **报错就贴原文**：把完整报错贴给 AI，说"先分析根因再修，不许猜"；
6. **验收靠截图对照**：让 AI 用 Playwright 打开我们的页面和参照系统页面分别截图，逐区块比对；
7. **看不懂就问**：随时问"这段代码是干什么的？用大白话解释"。

## 第十二部分：日常运维（上线后每周 10 分钟）

| 频率 | 动作 |
|---|---|
| 每天 | 瞄一眼定时任务是否正常（或等失败告警邮件） |
| 每周 | 看 DeepSeek 用量和费用；看备份文件是否在增长；`docker compose logs --tail=100` 扫一眼报错 |
| 每月 | 服务器系统补丁更新；检查磁盘占用（`df -h`）；回顾配额是否合理 |
| 数据源挂了 | 看采集告警 → 检查 akshare 是否改版 → 升级 `pip install -U akshare` 或切备用源 |

### 常见故障自救

| 症状 | 处理 |
|---|---|
| 网站打不开 | SSH 上去 `docker compose ps` 看哪个容器挂了 → `docker compose restart` |
| 首页行情不更新 | 看 Worker 日志，多半是数据源接口变了 |
| AI 报告失败 | 看 `task_records.error`；DeepSeek 余额不足或限流居多 |
| 磁盘满 | 清 Docker 旧镜像 `docker system prune -a`；清旧备份 |
